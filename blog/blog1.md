# Blog 1: What Is Data Science to Me?

Data science to me is a field where you have to be able to use data to make smart real-time decisions. Data scientists are basically the brains that have to answer a question worth asking and  essentially like finding a method to the madness. The method can be whatever lane you choose to make sense of the data you are working with, whether it be SQL, Python, or even machine learning. You are basically tasked with figuring out which question is worth asking, then communicating what you found.

After starting to work on my first project in DTSC2301 I felt like this has mostly reaffirmed what I thought. A lot of what we do as data scientists is really just organization. We need to make sense of the numbers and what is going on with the information, and we also need to assist others in doing so.
