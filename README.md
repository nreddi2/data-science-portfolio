# Data Science Portfolio

This repository contains my DTSC 2301 portfolio and a reproducible exploratory analysis of wage and salary income differences in North Carolina using the 2024 ACS 1-Year PUMS API.

## Contents

- `index.md` - portfolio homepage
- `projects.md` - project index
- `gender-pay-gap.md` - Project 1 write-up
- `analysis/gender_pay_gap_acs.ipynb` - analysis code
- `assets/images/` - project visualizations
- `resume.pdf` - downloadable resume

## Reproducibility

The analysis notebook documents the Census API request, pandas cleaning process, weighted descriptive summaries, and visualizations. API keys are private and are not included in this repository.
